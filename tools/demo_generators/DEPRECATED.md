# DEPRECATED

These legacy demo generators are superseded by the unified demo store translator.

## New system

All demos are now generated by a single translator:

```bash
python tools/demo_store/generate_all.py
```

See `docs/demo_store/DEMO_STORE_GUIDE.md` for documentation.

## Migration

| Old script | Replacement |
|-----------|------------|
| `verified/generate_qe_demos.py` | `tools/demo_store/generate_all.py` (QE demos preserved from existing) |
| `verified/generate_orca_demos.py` | Translator pipeline via corpus |
| `verified/generate_pyscf_demos.py` | Direct snapshot via corpus |
| `verified/generate_wannier90_demos.py` | Preserved from existing demos |
| `migrate_demo_projects.py` | No longer needed |
| `verify_demos.py` | `tests/integrity/backend/test_demo_lifecycle.py` |
